## 🎨 Design e Funcionalidades

- **Design Premium**: Interface rica, cores harmoniosas e tipografia moderna.
- **Responsividade Total**: Experiência fluida em desktops, tablets e smartphones.
- **Interatividade**: Micro-interações e animações suaves para maior engajamento do usuário.
- **Servidor Local**: Configuração simples e ágil usando Node.js com Express para testes e desenvolvimento.

---

## 💻 Tecnologias Utilizadas

O projeto utiliza um stack sólido para garantir boa performance e manutenibilidade:

- **HTML5**: Estrutura semântica e acessível.
- **CSS3**: Estilização rica com animações nativas.
- **JavaScript (Vanilla)**: Lógica de interface sem dependências complexas.
- **Bootstrap 5.3**: Componentes e sistema de grid para agilizar o layout.
- **Node.js & Express**: Servidor web leve e rápido.

---

## ⚙️ Como Executar o Projeto

É muito fácil rodar o projeto no seu ambiente local. Siga os passos abaixo:

1. **Abra o terminal** na pasta raiz do projeto (`02-site-serliv`).
2. **Instale as dependências** do Node.js executando:
   ```bash
   npm install
   ```
3. **Inicie o servidor local** com o comando:
   ```bash
   npm start
   ```
4. **Acesse no seu navegador**: [http://localhost:3000](http://localhost:3000)
